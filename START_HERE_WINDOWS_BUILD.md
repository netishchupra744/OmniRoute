# Start Here — Create the Windows EXE

The source is configured to build the existing OmniRoute Electron application as **Bijoy AI Video Maker**.

## No-terminal GitHub method

1. Put this source in a GitHub repository.
2. Open the repository's **Actions** tab.
3. Select **Build Bijoy AI Video Maker Windows Installer**.
4. Click **Run workflow**.
5. Open the completed run and download **Bijoy-AI-Video-Maker-Windows**.

The downloaded artifact contains the Setup EXE, Portable EXE, SHA-256 checksums and build manifest.

See `docs/BUILD_WINDOWS_INSTALLER.md` for technical details.
